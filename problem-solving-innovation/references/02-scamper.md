# SCAMPER 奔驰法

## 一句话定义
通过七个系统化操作维度（替代、合并、调整、修改、他用、消除、反向）对现有产品或方案进行改良创新。

## 核心原理与步骤

**原理：**
创新不一定是从零发明，更多是对已有事物的重新组合和改造。SCAMPER 提供了七个明确的操作方向，把"想创意"变成"按维度穷举"。

**七个操作维度：**

| 字母 | 维度 | 核心提问 |
|------|------|----------|
| S | Substitute（替代） | 什么成分/材料/流程可以被替换？ |
| C | Combine（合并） | 能否把两个功能/产品/流程合在一起？ |
| A | Adapt（调整） | 有什么其他领域的做法可以借鉴过来？ |
| M | Modify/Magnify（修改/放大） | 放大/缩小/改变形状/颜色会怎样？ |
| P | Put to other uses（他用） | 这个东西还能用在别的场景吗？ |
| E | Eliminate（消除） | 去掉哪部分反而更好？ |
| R | Reverse/Rearrange（反向/重排） | 颠倒顺序、反转角色会怎样？ |

**操作步骤：**
1. 明确你要改良的对象（产品、流程、服务、功能）
2. 依次对七个维度提问，每个维度至少产出3个想法
3. 不评判，先穷举
4. 穷举完再筛选可行性和价值

## 适用场景
- 现有产品需要迭代升级但没有突破方向时
- 流程改善，想找优化空间
- 竞品分析后需要差异化
- 头脑风暴卡住时，用SCAMPER强制切换角度
- 教育培训中的创意训练

## 实操案例
**对象：** 普通雨伞

- **S替代：** 伞面用疏水纳米涂层布料替代传统尼龙 → 永远不湿
- **C合并：** 伞+手杖 → 适合老人的多用途伞
- **A调整：** 借鉴帐篷的折叠结构 → 超小折叠伞
- **M修改：** 加大伞面 → 双人伞
- **P他用：** 伞柄内置手电筒 → 夜间照明伞
- **E消除：** 去掉伞柄 → 戴在头上的伞帽
- **R反向：** 伞面朝上收集雨水 → 雨水收集装置

**关键洞察：** SCAMPER的价值不在于某一个维度能产出好创意，而在于七个维度穷举后，你会发现自己从未考虑过的方向。
