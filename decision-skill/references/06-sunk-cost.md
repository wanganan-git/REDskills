# 沉没成本

> 本文档是沉没成本模型的完整文档。读取后按以下结构向用户输出：适用场景 → 底层逻辑 → 核心解读 → 决策清单 → 真实案例 → 不适合的场景 → 搭配用法。末尾必须给出「你现在可以这样做」的行动建议。

## 适用场景

- 纠结要不要放弃已经投入很多的事
- 一段关系/工作/项目明显不行了，但舍不得抽身
- 「来都来了」「买都买了」的心态作祟时
- 投入越多越难放手的恶性循环
- 做新决策时被过去的投入绑架

## 底层逻辑

源自经济学和行为心理学（理查德·塞勒的「禀赋效应」研究）：已经付出且无法收回的成本，叫做沉没成本。理性决策应该只考虑未来的成本和收益，但人天生会被过去的投入影响判断——这就是「沉没成本谬误」。

大脑把「放弃」等同于「承认失败」，所以宁愿继续痛苦地坚持，也不愿意止损。这不是理性，是损失厌恶在作祟。

## 核心解读

沉没成本的本质不是「花了多少钱/时间」，而是「过去的投入对未来决策没有参考价值」。

你花 300 元买了一张电影票，看了 30 分钟发现是烂片。此时你的选择只有一个：接下来的 90 分钟怎么安排最有价值。那 300 元已经花了，不管你看不看完，都回不来了。

但大多数人的逻辑是：「我都花了 300 了，不看完太亏了。」于是又浪费 90 分钟看烂片——真正亏的不是 300 元，而是那 90 分钟。

沉没成本决策原则：只问「从现在开始，继续做和放弃，哪个对未来更有利」。过去投入的再多，都不是继续的理由。

## 决策清单

- [ ] 写下你纠结要不要放弃的事
- [ ] 列出已经投入的成本：时间、金钱、精力、情感
- [ ] 对每项已投入成本写一句话：「这些已经收不回来了」
- [ ] 把所有已投入成本从决策因素中划掉
- [ ] 只从「此刻」出发，问自己：
  - 继续做，未来预期收益是什么？
  - 继续做，未来需要付出什么代价？
  - 收益 > 代价 → 继续
  - 收益 < 代价 → 果断放弃
- [ ] 如果发现「继续的理由只剩下不想浪费之前的投入」→ 这就是沉没成本谬误，该止损了

## 真实案例

**案例：一份工作做了 3 年，越来越痛苦，但舍不得辞职**

用模型前的思维：「我都干了 3 年了，现在走之前的积累不就白费了吗？再坚持坚持吧。」

用沉没成本分析：
1. 已投入成本：3 年时间、积累的行业经验、同事关系
2. 关键判断：这些投入「已经完成了」——3 年经验不会因为你离职而消失，它已经长在你身上了
3. 从此刻出发：
   - 继续做：收入稳定，但每天痛苦，没有成长，状态持续下滑
   - 辞职：短期收入风险，但有机会找到更适合的方向
4. 真正的问题不是「之前 3 年白费了吗」，而是「继续待下去，未来 3 年会怎样」
5. 结论：如果未来收益（成长+状态）明显低于代价（痛苦+消耗），就该止损。之前 3 年的经验是你的资产，不是你的枷锁。

## 不适合的场景

- 短期困难期——困难是阶段性的，不代表方向错了。区分「该坚持」和「该止损」
- 契约/承诺类决策——签了合同、做了承诺，不能只算经济账
- 沉没成本很小的情况——纠结的精力成本可能比沉没成本还高

## 搭配用法

| 搭配模型 | 为什么能搭 | 用法 |
|---------|-----------|------|
| 机会成本 | 一个放下过去，一个看清未来 | 先用沉没成本放下已投入的，再用机会成本评估止损后的新选择有多大价值 |
| 逆向思维 | 一个放下过去，一个预判未来 | 先用沉没成本放下已投入的，再用逆向思维推演「如果继续下去，最坏结果是什么」 |
| 复利效应 | 判断止损后的新方向是否有长期积累价值 | 放下沉没成本后，用复利效应评估新方向是否值得长期投入 |
