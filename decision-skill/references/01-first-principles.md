# 第一性原理

> 本文档是第一性原理模型的完整文档。读取后按以下结构向用户输出：适用场景 → 底层逻辑 → 核心解读 → 决策清单 → 真实案例 → 不适合的场景 → 搭配用法。末尾必须给出「你现在可以这样做」的行动建议。

## 适用场景

- 重大方向选择（转行、创业、定居）
- 被「大家都这样做」裹挟时
- 创新决策、突破常规思路
- 分辨谣言、伪逻辑、营销话术
- 长期路线判断

## 底层逻辑

源自亚里士多德的哲学概念：在每个系统中存在最基本的命题，它不能被违背或删除。应用到决策中——抛开类比、经验、惯例，回到事物最底层的事实和规则，从零推导结论。

类比推理（别人这样做所以我这样做）只能产生微创新，第一性原理才能产生颠覆性判断。

## 核心解读

大多数人做决策靠的是「类比」——看别人怎么做、看过去怎么做、看行业惯例怎么做。这些参考在很多时候有效，但它们是别人在特定条件下得出的结论，不是底层真相。

第一性原理要求你把所有「二手结论」暂时放到一边，找到这件事最底层的事实，然后从事实出发一步步推导出自己的结论。

关键区分：底层事实 ≠ 个人直觉。底层事实是客观存在的规则、数据、物理限制；个人直觉是「我感觉这样对」。把直觉当底层逻辑，是使用这个模型最常见的错误。

## 决策清单

- [ ] 写下当前困扰你的选择/问题
- [ ] 列出你对这件事的所有「常识」「经验」「别人说」
- [ ] 逐条追问：这是事实还是观点？有没有例外？
- [ ] 找到 2-3 个不可推翻的底层事实（客观规则、数据、基本需求）
- [ ] 从这些底层事实出发，重新推导：如果不参考任何现有做法，最优解是什么？
- [ ] 对比推导结果和你原来的想法，差异在哪？差异的原因是什么？
- [ ] 做出选择

## 真实案例

**案例：纠结要不要转行做自媒体**

用模型前的思维：「现在自媒体很火，很多人都在做，我也想试试。但又怕不稳定，毕竟现在的工作虽然不喜欢但至少有保障。」

用第一性原理拆解：
1. 底层事实 1：我工作的核心需求是——收入稳定 + 有成长空间 + 不讨厌
2. 底层事实 2：自媒体的收入模式是——前期零收入，后期取决于内容质量和持续性
3. 底层事实 3：我当前的财务状况——有 6 个月生活费储备
4. 从底层推导：如果核心需求是收入稳定，那自媒体前期不能全职；如果核心需求是成长，那要看自己是否有持续产出内容的能力和意愿
5. 推导结论：先兼职做 3 个月验证，有正反馈再考虑全职——而非「别人都在做所以我也做」或「怕不稳定所以不做」

## 不适合的场景

- 日常琐事（吃什么、穿什么）——杀鸡用牛刀
- 纯情绪问题（失恋、心情低落）——需要的是共情，不是逻辑拆解
- 信息严重不足时——底层事实都找不到，无法推导

## 搭配用法

| 搭配模型 | 为什么能搭 | 用法 |
|---------|-----------|------|
| 系统思维 | 第一性原理找到本质，系统思维看清本质在全局中的位置 | 先用第一性原理拆出底层需求，再用系统思维看这个需求和其他因素的关联 |
| 逆向思维 | 正向推导+反向验证，双重检验结论 | 用第一性原理推导出方案后，用逆向思维推演「如果这个方案失败，最可能的原因是什么」 |
| 羊群效应 | 一个破除经验依赖，一个破除从众依赖 | 先用羊群效应识别自己是否在跟风，再用第一性原理回归真实需求 |
