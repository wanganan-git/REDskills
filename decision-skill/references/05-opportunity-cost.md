# 机会成本

> 本文档是机会成本模型的完整文档。读取后按以下结构向用户输出：适用场景 → 底层逻辑 → 核心解读 → 决策清单 → 真实案例 → 不适合的场景 → 搭配用法。末尾必须给出「你现在可以这样做」的行动建议。

## 适用场景

- 二选一、多选一的任何场景
- 资源有限（时间、金钱、精力）时的分配决策
- 选工作、选专业、选城市
- 消费决策（买 A 还是买 B）
- 时间分配（做 A 事还是 B 事）

## 底层逻辑

源自经济学核心概念（弗里德曼、布坎南等经济学家系统阐述）：任何选择都有代价，代价不是你付出了什么，而是你放弃了什么。

当你选择 A，你放弃的 B、C、D 中最好的那个，就是你选择 A 的机会成本。这才是你为这个选择付出的真实代价。

## 核心解读

大多数人评估一个选择时，看的是「我得到了什么」。但真正决定这个选择值不值的，是「我为此放弃了什么」。

举个极端例子：你花 3 小时看了一部烂电影。你的损失不只是电影票钱和 3 小时时间，而是这 3 小时你本可以做的最有价值的事——比如学一门课、见一个重要的人、好好睡一觉。那个被放弃的「最有价值的事」才是你的真实成本。

机会成本的核心价值在于：它强迫你从「这个选择好不好」切换到「这个选择比其他选择好多少」。绝对好坏没有意义，相对优劣才是决策依据。

## 决策清单

- [ ] 写下你面临的选择（至少 2 个选项）
- [ ] 列出每个选项的直接收益（能得到什么）
- [ ] 列出每个选项的直接代价（要付出什么）
- [ ] 关键步骤：对每个选项，写下「选了它就等于放弃什么」——被放弃的选项中最好的那个
- [ ] 计算每个选项的「净收益 = 直接收益 - 机会成本」
- [ ] 选净收益最高的
- [ ] 接受一个事实：任何选择都有机会成本，不存在「零代价」的完美选项

## 真实案例

**案例：周末 2 天，是出去旅游还是在家学习**

用模型前的思维：「好久没出去玩了，想放松一下。但又觉得应该学习提升自己。好纠结。」

用机会成本分析：
1. 选项 A（出去旅游）：
   - 直接收益：放松身心、体验新环境、社交
   - 直接代价：金钱 500 元、体力消耗
   - 机会成本：放弃 2 天集中学习的成果（假设能学完一门课的 30%）
2. 选项 B（在家学习）：
   - 直接收益：技能提升、完成课程进度
   - 直接代价：精力消耗、可能枯燥
   - 机会成本：放弃放松和体验的机会
3. 关键判断：哪个机会成本更不可接受？
   - 如果最近压力很大、状态很差 → 放松的边际收益更高，选旅游
   - 如果有个考试/项目 deadline 临近 → 学习的边际收益更高，选学习
4. 结论：不是「旅游好不好」或「学习好不好」，而是「在当前状态下，放弃哪个更可惜」

## 不适合的场景

- 没有明确替代选项时——只有一个选择，不存在机会成本
- 选项之间差异极大无法比较——比如「去北京还是去月球」
- 纯情感决策——有时候明知机会成本高，但情感上就是需要，这也是一种理性

## 搭配用法

| 搭配模型 | 为什么能搭 | 用法 |
|---------|-----------|------|
| 沉没成本 | 一个看过去，一个看未来 | 先用沉没成本放下已投入的，再用机会成本评估未来的取舍 |
| 二八法则 | 机会成本算总账，二八法则找重点 | 列出所有选项后，用二八法则判断哪个选项的核心价值最高 |
| 概率思维 | 机会成本算期望值，概率思维给概率 | 用概率思维评估每个选项收益的实现概率，再算加权后的机会成本 |
