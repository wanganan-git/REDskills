# 系统思维

> 本文档是系统思维模型的完整文档。读取后按以下结构向用户输出：适用场景 → 底层逻辑 → 核心解读 → 决策清单 → 真实案例 → 不适合的场景 → 搭配用法。末尾必须给出「你现在可以这样做」的行动建议。

## 适用场景

- 一件事影响多个环节或多方利益相关者
- 短期有利但长期有害的选择
- 需要预判连锁反应的决策
- 涉及资源分配、优先级排序的复杂问题
- 个人生活中的「牵一发动全身」类选择

## 底层逻辑

源自系统动力学（MIT 福瑞斯特教授创立）：任何事物都不是孤立存在的，而是由多个相互关联的要素组成的系统。系统中一个要素的变化会通过反馈回路影响其他要素，产生非线性的连锁反应。

应用到决策中——不要孤立地看一个问题，要把问题放进它所在的系统里，看清各个要素之间的因果关系和反馈回路。

## 核心解读

人的大脑天然喜欢「线性因果」——因为 A 所以 B，简单清晰。但现实世界是「网状因果」——A 影响 B，B 影响 C，C 又反过来影响 A。

系统思维的核心是识别三种东西：
1. **要素**：这件事涉及哪些人、哪些环节、哪些资源
2. **连接**：这些要素之间怎么互相影响
3. **反馈回路**：哪些影响会自我强化（正反馈），哪些会自我调节（负反馈）

一个决策好不好，不能只看它对单一要素的影响，要看它对整个系统的影响——尤其是长期的、间接的、容易被忽略的影响。

## 决策清单

- [ ] 写下你面临的选择/问题
- [ ] 列出这个选择涉及的所有要素：人、资源、时间、环节、利益相关者
- [ ] 画出要素之间的因果关系：A 影响 B 的方向是正向还是负向
- [ ] 识别正反馈回路：有没有哪个变化会自我强化？（如：熬夜→效率低→更需要熬夜）
- [ ] 识别负反馈回路：有没有哪个变化会自我调节？（如：涨价→需求减少→价格回落）
- [ ] 预判短期影响（1-3 个月）和长期影响（1-3 年）
- [ ] 找到最容易被忽略的间接影响
- [ ] 选择对整个系统长期最优的方案

## 真实案例

**案例：要不要为了赶项目连续加班一周**

用模型前的思维：「项目 deadline 紧，加一周班就能搞定，值得。」

用系统思维分析：
- 要素：项目进度、身体状态、工作效率、团队协作、后续项目
- 短期影响：项目按时交付（+）、身体疲劳（-）
- 连锁反应：
  - 身体疲劳 → 第二周效率暴跌 → 后续项目延期
  - 连续加班 → 情绪烦躁 → 和家人/同事关系紧张
  - 按时交付 → 领导信任 → 下次继续压 deadline（正反馈回路）
- 系统判断：短期收益（按时交付）被长期代价（效率损失 + 恶性循环）抵消。更优方案：和领导沟通砍掉非核心需求，或申请 2 天延期。

## 不适合的场景

- 单一变量的简单问题——不需要画系统图
- 时间紧迫到没有分析空间——先活下来再说
- 信息严重不足——连接关系都看不清，分析无意义

## 搭配用法

| 搭配模型 | 为什么能搭 | 用法 |
|---------|-----------|------|
| 第一性原理 | 一个看全局，一个看底层 | 先用第一性原理找到核心问题，再用系统思维看核心问题在全局中的位置 |
| 复利效应 | 系统思维看结构，复利效应看时间维度 | 用系统思维识别正反馈回路后，用复利效应评估这个回路的长期累积影响 |
| 奥卡姆剃刀 | 系统思维容易过度复杂化，奥卡姆剃刀帮你砍 | 画完系统图后，用奥卡姆剃刀砍掉影响微弱的次要连接，聚焦核心因果链 |
