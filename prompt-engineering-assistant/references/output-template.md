# 提示词输出模板

本文档定义了提示词输出的标准格式，确保每次输出都包含完整的信息和清晰的说明。

---

## 输出结构

每次生成提示词时，**必须**按以下结构输出：

```markdown
# [提示词标题]

## 📝 完整提示词

\`\`\`
[这里是完整的、可直接使用的提示词内容]
\`\`\`

---

## 📖 使用说明

[如何使用这个提示词的步骤说明]

---

## ⚙️ 参数说明

[哪些地方可以自定义修改，以及如何修改]

---

## 🔄 变体建议

[不同场景下如何调整这个提示词]
```

## 详细说明

### 第一部分：完整的提示词

**要求**:
- 格式：用代码块（\`\`\`）包裹
- 内容：结构化的完整提示词，可直接复制使用
- 包含：根据所选框架的完整要素

**示例**:

````markdown
```markdown
你是一名专业的产品文案撰写专家。

# 任务
撰写一篇吸引人的产品发布文案。

- 目标受众：25-35岁职场人士

# 要求
1. 标题：简洁有力，不超过15字
2. 正文：200-300字，突出核心卖点
3. 风格：专业、亲和、有感染力
4. 结尾：明确的行动召唤

# 示例参考

示例 1:
产品：运动手表
文案：[具体文案内容...]

示例 2:
产品：蓝牙音箱
文案：[具体文案内容...]

---

现在请为以下产品撰写文案：
产品：{{用户输入的产品信息}}
```
````

### 第二部分：使用说明

**要求**:
- 清晰说明如何使用这个提示词
- 包含使用步骤
- 说明预期效果

**模板**:

```markdown
## 📖 使用说明

### 使用步骤
1. **准备输入**: [说明需要准备什么信息]
2. **替换变量**: 将 `{{变量名}}` 替换为实际内容
3. **发送请求**: 将提示词发送给 Claude/GPT 等 AI 模型
4. **调整优化**: 根据输出结果，微调提示词

### 预期效果
- ✅ [效果1]
- ✅ [效果2]
- ✅ [效果3]

### 注意事项
- ⚠️ [使用中需要注意的问题1]
- ⚠️ [使用中需要注意的问题2]
```

**示例**:

```markdown
## 📖 使用说明

### 使用步骤
1. **准备产品信息**: 收集产品的核心特性、目标受众、使用场景
2. **替换变量**: 将提示词中的 `{{用户输入的产品信息}}` 替换为实际产品描述
3. **发送请求**: 将完整提示词发送给 AI 模型
4. **迭代优化**: 根据生成的文案质量，调整"要求"部分的字数、风格等参数

### 预期效果
- ✅ 生成符合目标受众语言习惯的文案
- ✅ 突出产品核心卖点
- ✅ 包含明确的行动召唤

### 注意事项
- ⚠️ 如果生成的文案过于生硬，可在"风格"部分增加更具体的形容词（如"轻松幽默"、"专业严谨"）
- ⚠️ 如果文案不够吸引人，可在"要求"中增加"使用问句开头"、"加入生活化场景"等技巧
```

### 第三部分：参数说明

**要求**:
- 列出提示词中可以自定义的部分
- 说明每个参数的作用和如何调整
- 用表格形式清晰展示

**模板**:

```markdown
## ⚙️ 参数说明

| 参数 | 位置 | 说明 | 可选值/示例 |
|------|------|------|-------------|
| [参数1] | [在提示词中的位置] | [参数作用] | [可选值或示例] |
| [参数2] | [在提示词中的位置] | [参数作用] | [可选值或示例] |

### 调整建议
- **[参数1]**: [如何根据场景调整]
- **[参数2]**: [如何根据场景调整]
```

**示例**:

```markdown
## ⚙️ 参数说明

| 参数 | 位置 | 说明 | 可选值/示例 |
|------|------|------|-------------|
| 目标受众 | "# 上下文" 部分 | 文案面向的人群 | "25-35岁职场人士"、"大学生"、"退休人群" |
| 字数要求 | "# 要求" 第2点 | 控制文案长度 | "200-300字"、"100字以内"、"500字左右" |
| 风格 | "# 要求" 第3点 | 文案的语言风格 | "专业"、"亲和"、"幽默"、"严肃" |
| 示例数量 | "# 示例参考" 部分 | Few-Shot 示例数量 | 2-5个 |

### 调整建议
- **目标受众**: 不同受众需要不同的语言风格。例如：年轻人→轻松活泼；专业人士→严谨数据
- **字数要求**: 根据使用场景调整。社交媒体短文案→100字内；官网详情页→500字+
- **风格**: 与品牌调性保持一致。科技公司→专业；生活品牌→温馨
- **示例数量**: 示例越多，AI 越容易理解期望，但也会占用更多 token。2-3个是最佳平衡点
```

### 第四部分：变体建议

**要求**:
- 针对不同场景提供调整方向
- 说明如何修改提示词以适应新场景
- 给出具体的修改建议

```markdown

**示例**:

[修改后的关键部分]
\`\`\`

**修改方法**:
- [修改点1]: [具体怎么改]
- [修改点2]: [具体怎么改]

**示例**:
\`\`\`
[修改后的关键部分]
\`\`\`
```

**示例**:

## 常见问题

**Q: 变体建议一定要提供3个吗？**

A: 不是必须。如果任务场景单一，1-2个变体即可。如果任务有多种常见使用场景，可以提供更多。

**Q: 参数说明可以省略吗？**

A: 不建议。参数说明帮助用户理解如何自定义提示词，是提示词可复用性的关键。

**Q: 使用说明可以简化吗？**

A: 可以根据任务复杂度调整。简单任务可以用3-5个要点说明，复杂任务需要详细步骤。
