# 高级提示词技巧

本文档收录超越基础框架的进阶策略和特定场景优化技巧。

---

## 一、基础核心技巧深化

### 1. 正向指令原则（"要什么" > "不要什么"）

**核心思想**: 给 AI 一个清晰的目标，而不是一个雷区。

**为什么有效**:
- 正向指令告诉 AI "往哪走"，负向指令只说"别去哪里"
- AI 需要明确的方向，而非边界限制

**示例对比**:

| 差的（负向） | 好的（正向） |
|-------------|-------------|
| "语气别太随意。" | "请使用正式、学术的语调写作。" |
| "不要写太长。" | "请用简洁的语言，控制在200字以内。" |
| "别用太多专业术语。" | "用通俗易懂的语言，适合非专业读者理解。" |

**如何结合使用**:
- **主要指令用正向**: "详细说明产品特性..."
- **边界控制用负向**: "...但不要涉及价格或促销信息"

**提示词模板**:
```
任务：[明确的正向目标]

约束：
- [负向约束1，用于明确边界]
- [负向约束2，用于排除不需要的内容]
```

---

### 2. 细节与上下文原则

**核心思想**: AI 不是你肚子里的蛔虫，提供所有重要的细节和上下文。

**必须包含的上下文要素**:
- **任务背景**: 为什么需要做这个任务？
- **目标受众**: 谁会看到/使用结果？
- **使用场景**: 结果会在什么情况下被使用？
- **已有信息**: 之前做过什么？有哪些参考？

**示例**:

❌ **差的提示词**:
```
"分析下这个。"
```

✅ **好的提示词**:
```
# 任务背景
这是一份用户满意度调查数据，我们需要了解用户最不满意的方面。

# 分析要求
总结这份调查数据的关键发现，重点关注：
1. 用户抱怨最多的3个问题
2. 不同用户群体的满意度差异
3. 与去年相比的变化趋势

# 输出格式
请用项目符号列表展示，每个发现包含具体数据支持。
```

## 二、进阶策略技巧

### 3. 链式思考（Chain of Thought, CoT）

**核心思想**: 要求 AI 展示推理过程，大幅提升复杂问题的准确率。

**魔法咒语**:
- "Let's think step by step."
- "让我们一步步地解决这个问题。"
- "请先分析，再给出结论。"

**适用场景**:
- 数学计算
- 逻辑推理
- 复杂分析
- 多步骤问题

**标准模板**:

```markdown
# 任务
[任务描述]

# 要求
请使用链式思考方法完成这个任务：

1. **问题分解**: 将这个问题拆解为几个子问题？
2. **逐步分析**: 对每个子问题进行详细分析
3. **综合结论**: 基于分析得出最终结论

请清晰展示你的思考过程，不要直接跳到结论。
```

**示例**（数学问题）:

```
问题：一个农场有鸡和兔子共50只，腿共140条，问鸡和兔子各多少？

请一步步思考：
1. 设鸡有x只，兔子有y只，列出方程组
2. 解这个方程组
3. 验证答案是否符合题意
```

### 4. 逆向工程技巧

**核心思想**: 把优秀的成品给 AI，让它反推生成这个结果的提示词。

**使用场景**:
- 学习某种风格
- 复制成功案例
- 理解优秀作品的底层逻辑

**提示词模板**:

```markdown
# 任务
这是我想要的成品范例。

[范例内容：文章/图片描述/代码等]

请你：
1. 倒推一个提示词，让我用它能稳定生成同风格的内容
2. 分析这个范例的核心特征和结构
3. 给出可复用的提示词模板
```

**实际应用**:

**示例 1**（文案风格）:
```
这是一篇爆款小红书文案：
[文案内容]

请分析这篇文案的写作技巧，并帮我写一个提示词模板，让我以后能写出类似风格的文案。
```

**示例 2**（编程）:
```
这是一段优雅的代码：
[代码内容]

请分析这段代码的设计模式和优点，然后给我一个提示词，让 AI 以后写出这种风格的代码。
```

### 5. 双层解释法

**核心思想**: 用两种方式解释同一个概念，对照学习，理解更透彻。

**模板**:

```markdown
请帮我解释【概念名称】。

**版本1：初学者版本**
面向：[具体人群，如"洗脚城的大爷"、"小学五年级学生"]
要求：用生活化的语言、类比、例子，避免专业术语

**版本2：专业版本**
面向：[具体人群，如"行业专家"、"研究生"]
要求：精确的专业术语、技术细节、前沿研究

**对比分析**
请对比两个版本的差异，说明如何在不同场景中选择合适的解释方式。
```

**示例**:

```
请解释"机器学习"这个概念。

初学者版本：
面向：完全不懂技术的高中生
用生活中的例子和类比

专业版本：
面向：计算机专业本科生
包含算法原理、数学基础、应用场景
```

### 6. 预演失败（事前验尸）

**核心思想**: 在启动项目前，让 AI 假设项目失败，提前发现风险。

**使用场景**:
- 项目规划
- 产品发布
- 重要决策
- 方案评估

**提示词模板**:

```markdown
# 项目/方案
[项目或方案的详细描述]

# 任务
请假设这个项目在6个月后**失败了**。

请回答：
1. **失败时间点**: 什么时间点开始出现衰退信号？
2. **致命错误**: 最致命的决策错误是什么？
3. ** overlooked 风险**: 哪些风险被我们忽视了？
4. **预防措施**: 现在应该采取什么措施来避免这些失败？

请尽可能具体，给出时间线和具体场景。
```

**示例**:

```
# 项目
我们计划开发一款面向大学生的AI学习助手APP，包含以下功能：
- AI答疑
- 学习计划生成
- 知识点图谱
- 社群讨论

请假设这个项目在6个月后失败了，分析原因并给出预防建议。
```

## 三、特定场景高效技巧

### 7. AI 生视频/生图：时间线分段

**核心思想**: 按秒数分段描述画面和剧情转折，让模型精准把握节奏。

**标准格式**:

```
0-3秒：[镜头/画面描述]
3-5秒：[镜头/画面描述]
5-8秒：[镜头/画面描述]
...
```

**示例**:

```
# 视频脚本（15秒）

0-3秒：
- 画面：男主举起篮球，犹豫表情
- 台词："我只是...想打篮球而已。"
- 镜头：中景，正面拍摄

3-8秒：
- 画面：场景切换到古宅雨夜，男主身穿古装练武
- 镜头：慢镜头，从远景缓缓推近到人物特写
- 音效：雨声、古琴声

8-15秒：
- 画面：快速切换现代篮球场和古代练武场的对比画面
- 镜头：快速剪辑，节奏加快
- 结尾：定格在男主坚定的眼神
```

### 8. AI 生视频/生图：明确"参考"与"编辑"

**核心思想**: "参考"和"编辑"是两个不同概念，必须写清楚。

| 概念 | 含义 | 示例 |
|------|------|------|
| **参考** | 借鉴风格、技巧、元素 | "参考@视频1的运镜方式和色调" |
| **编辑** | 修改原内容的具体部分 | "将@视频1中的女生换成戏曲花旦" |

**常见错误**:

❌ **混淆使用**:
```
"编辑@视频1的运镜方式"
→ 运镜方式是抽象的风格，无法"编辑"
```

✅ **正确使用**:
```
"参考@视频1的运镜方式"
→ 借鉴风格
```

```
"将@视频1的背景换成赛博朋克城市"
→ 编辑具体元素
```

### 9. AI 生视频/生图：镜头语言写具体

**专业术语**:

| 术语 | 说明 | 示例 |
|------|------|------|
| **推** | 镜头向主体移动 | "缓慢推向人物面部特写" |
| **拉** | 镜头远离主体 | "从人物拉远到全景" |
| **摇** | 镜头左右/上下转动 | "摇镜头展示城市全景" |
| **移** | 镜头平行移动 | "跟随人物移动" |
| **仰拍** | 从下往上拍 | "仰拍表现人物高大" |
| **俯拍** | 从上往下拍 | "俯拍展示战场布局" |
| **一镜到底** | 长镜头不剪辑 | "一镜到底跟随主角进入房间" |
| **希区柯克变焦** | 移动+变焦同时进行 | "希区柯克变焦表现眩晕感" |

**大白话版本**（如果不熟悉术语）:
```
"从远处慢慢走到人物面前"
"像眼睛一样环顾四周"
"从高往下看整个场景"
```

**示例**:

```
专业版：
"0-5秒：使用希区柯克变焦，镜头缓慢后推，背景逐渐压缩，突出主角的震惊表情。"

大白话版：
"0-5秒：镜头慢慢后退，同时让背景感觉越来越近，像主角的世界在崩塌。"
```

### 10. AI 编程：迭代优化与 TDD

**核心思想**: 不要一次写完，分步骤逐步增加功能。

**方法 1：迭代优化**

```
第一轮：
"写一个简单的快速排序函数，用Python实现。"

第二轮：
"很好。现在给这个函数加上详细的注释。"

第三轮：
"现在加一个参数，可以选择升序或降序。"

第四轮：
"最后加上输入验证和错误处理。"
```

**方法 2：测试驱动开发（TDD）**

```markdown
# 任务
使用TDD方法开发一个用户登录功能。

请按以下顺序：

1. **先写测试用例**:
   - 正确的用户名和密码应登录成功
   - 错误的密码应返回错误
   - 不存在的用户应返回错误
   - 空输入应返回错误

2. **再写实现代码**:
   - 实现满足这些测试的函数

3. **验证测试**:
   - 运行测试用例，确保全部通过
```

### 11. 内容创作：展示而非告知（Show, Don't Tell）

**核心思想**: 别让 AI 直接说"他很悲伤"，而是描写场景来"展示"悲伤。

**对比示例**:

| 告知（差） | 展示（好） |
|-----------|-----------|
| "他很悲伤。" | "他盯着冰冷的咖啡，雨滴滑过窗户，远处的钟声敲了十二下。" |
| "房间很乱。" | "衣服堆在椅子上，书本散落在地板，桌子上放着半个吃剩的苹果。" |
| "她很紧张。" | "她不停地转着手中的笔，呼吸急促，眼神不敢与对方接触。" |

**提示词模板**:

```markdown
# 写作原则
使用"展示而非告知"的技巧。

# 要求
- ❌ 不要直接用形容词描述情绪/状态（如"他很生气"）
- ✅ 通过动作、环境、细节来间接展示
- 使用感官描写（视觉、听觉、触觉、嗅觉）

# 示例参考
[提供1-2个展示而非告知的例子]

---

现在请根据以上原则，写一段关于[场景]的描述。
```

## 四、综合应用示例

### 示例 1：AI 生视频提示词（综合运用）

```markdown
# 视频生成提示词

@参考视频1（借鉴运镜风格）
@首帧图片（作为第一帧画面）

# 时间线脚本（15秒）

**0-3秒：开场**
- 画面：赛博朋克城市夜景，霓虹灯闪烁
- 镜头：缓慢推镜头（Dolly In），从全景到中景
- 运动方式：参考@视频1的开场运镜

**3-8秒：人物登场**
- 画面：主角（穿黑色风衣）从阴影中走出
- 镜头：低角度仰拍，表现主角气场
- 细节：雨滴落在主角的风衣上

**8-12秒：动作特写**
- 画面：主角拔剑，金属反光
- 镜头：极慢镜头（Slow Motion），聚焦剑刃
- 光效：冷色调侧光，霓虹光反射

**12-15秒：定格**
- 画面：主角背影，剑指远方
- 镜头：拉镜头（Pull Back），展示城市全貌
- 氛围：孤独、决绝

# 技术参数
- 分辨率：4K
- 帧率：24fps
- 宽高比：16:9
- 风格：赛博朋克+写实风
```

### 示例 2：复杂分析任务（链式思考 + 双层解释）

```markdown
# 任务
分析为什么这个营销活动会失败。

# 要求
请使用以下方法进行分析：

## 1. 链式思考
请一步步分析：
- 目标受众是谁？
- 活动的核心信息是什么？
- 可能遇到什么问题？
- 如何改进？

## 2. 双层解释
**初学者版本**：
面向市场部实习生，用通俗语言解释失败原因

**专业版本**：
面向营销总监，使用专业术语分析战略层面的失误

## 3. 预演失败
假设活动已经失败并复盘：
- 失败的转折点在哪？
- 最大的决策失误是什么？
- 如果重来，应该怎么做？
```

## 六、最佳实践总结

1. **正向优先**: 用"要什么"定义方向，用"不要什么"划定边界
2. **上下文充足**: 假设 AI 对你的情况一无所知
3. **逐步深入**: 从简单开始，逐步增加复杂度
4. **展示过程**: 让 AI 展示思考过程，提升可靠性
5. **双向学习**: 用逆向工程理解优秀作品
6. **事前验尸**: 提前假设失败，规避风险
7. **精确描述**: 特定场景使用专业术语或精确描述
8. **迭代优化**: 不要一次追求完美，逐步改进
