## 1. 基础复盘框架

### 继续做/停止做/开始做（CSS 框架）

最基础的复盘逻辑，适用于任何单事件或短周期复盘：

- **继续做（Continue）**：哪些动作带来正向结果，需要保持？
- **停止做（Stop）**：哪些动作低效、有负反馈，需要立刻停止？
- **开始做（Start）**：哪些新尝试/改进动作，需要落地？

### 复盘三问

- 做对了什么？
- 做错了什么？
- 如果重来一遍，你该怎么做？

### PDCA 循环

Plan（计划）→ Do（行动）→ Check（检查/复盘）→ Act（处理/总结教训，放入下一个循环）

## 2. 四步法详解

适配目标导向复盘，每一步有明确的输入和输出：

### 第一步：成败认定

**目标**：统一认知，明确上半年是"成"还是"败"

**输入**：全年目标、上半年计划
**输出**：统一的完成度评估 + 复盘焦点

**关键提问**：
- 全年目标是什么？上半年拆解的子目标/关键结果是什么？
- 实际完成率是多少？和目标的差距？
- 本次复盘核心要讨论什么问题？不讨论什么？

**注意**：避免各执一词。比如销售额完成 40%，统一认知为"基本完成但进度滞后"，而非"成功"或"失败"。

### 第二步：场景还原

**目标**：区分「事实」与「判断」，只陈列可验证的客观信息

**关键原则**：
- 禁止主观归因和动机判断
- "招募了 7 名志愿者，差额 3 名"是事实
- "人事部门不给力"是判断，不允许出现

**关键提问**：
- 实际发生了哪些可验证的事实？
- 有哪些数据、文档、记录可以支撑？
- 关键节点的时间线是怎样的？

### 第三步：得失分析

**目标**：找到"下一次如何做"的方案

**亮点分析**：
- 做得好的地方，核心成功因素是什么？
- 哪些是可以复制的？

**不足分析**：
- 做得不好的地方，根本原因是什么？
- 有哪些关联因素？哪个因素权重最高？
- 之前的核心假设是否成立？

**工具：5 层阶梯思考法**：
1. 提炼发现（观察到了什么）
2. 找原因（为什么会这样）
3. 找所有关联要素（还有哪些因素）
4. 要素权重排序（哪个最重要）
5. 找关键假设（我们默认了什么）

### 第四步：总结提炼

**目标**：把复盘成果转化为可执行的行动

**输出要求**：
- 所有共识必须文字记录，否则等于没有共识
- 所有决议必须明确执行动作、截止时间、验收标准
- 所有经验教训必须归档，否则等于忘记知识

## 3. 个人成长四维体系详解

### 维度一：身体

**覆盖范围**：饮食、休息、运动、作息、体检、身体状态变化

**参考提问**：
- 这半年你的运动频率是多少？（次/周，每次多长时间）
- 体重/体脂有什么变化？有具体数据吗？
- 睡眠质量怎么样？平均每天睡几个小时？
- 有没有生病或就医？几次？什么原因？
- 饮食习惯有什么变化？

### 维度二：精神

**覆盖范围**：精神训练、抗压能力、心态调整、情绪管理

**参考提问**：
- 这半年你的整体精神状态怎么样？
- 有没有特别有成就感的时刻？具体是什么事？为什么让你有成就感？
- 有没有特别低落或压力大的时刻？是什么触发的？你怎么应对的？
- 你用了什么方式调节自己？（冥想、运动、社交、独处等）效果如何？
- 你的抗压能力和年初相比有什么变化？

### 维度三：智力

**覆盖范围**：阅读、写作、思考、技能提升、学习新事物

**参考提问**：
- 这半年你读了哪些书/文章/课程？哪些对你影响最大？
- 有哪些技能提升了？怎么衡量的？
- 有哪些想学但没开始的？为什么没开始？
- 你的思考方式或认知有什么变化？有没有推翻过之前的某个认知？
- 你输出了什么？（写文章、做分享、教别人等）

### 维度四：社会/情感

**覆盖范围**：人际关系、社会连接、情感状态、社交质量

**参考提问**：
- 这半年你的人际关系有什么变化？
- 有没有新认识的重要的人？怎么认识的？对你有什么影响？
- 有没有疏远或失去的关系？原因是什么？
- 你在亲密关系/家庭关系中有什么变化？
- 你的社交质量怎么样？有没有让你感到消耗的关系？

## 4. 提问工具箱

### 深度提问六步法

当某个维度需要深入挖掘时，用这六个问题逐层推进：

1. 你所需要解决的问题是什么？（定义清晰，不模糊）
2. 你为什么需要解决这个问题？（最终目的）
3. 解决这个问题，你的目标是什么？（可衡量的结果）
4. 达成这个目标，最核心的要素是什么？（抓重点，二八原则）
5. 针对这几个核心要素，有哪些解决方法？（穷尽可能性）
6. 根据你选的解决方法，接下来你具体要做什么？（落地动作）

### 归因追问

当用户给出结论但没有依据时：
- "你说 XX 做得不好，具体是什么数据或事件让你得出这个结论？"
- "你觉得是因为 XX，有没有其他可能的原因？"
- "这个原因和结果之间，是因果关系还是只是相关？"

### 数据追问

当用户给出模糊描述时：
- "具体是多少？有没有数据或记录？"
- "和年初相比，变化了多少？"
- "这个频率是每周/每月多少次？"

## 5. 归因方法

### 区分事实与判断

| 事实（可验证） | 判断（主观） |
|---------------|-------------|
| 上半年读了 20 本书 | 我读书很努力 |
| 体重从 85kg 降到 78kg | 身体状态变好了 |
| 完成了 3 个项目 | 工作表现不错 |
| 和朋友聚了 5 次 | 社交生活丰富 |

### 因果 vs 相关

- 相关性：A 和 B 同时发生
- 因果性：A 导致了 B

追问方式："除了 XX 之外，还有什么因素可能导致了这个结果？"

### 根因分析

对每个不足之处，追问三层：
1. 直接原因是什么？
2. 深层原因是什么？（为什么会有这个直接原因）
3. 根本假设是什么？（我们默认了什么，这个默认是否成立）

## 6. 常见误区

### 复盘时不要做的事

1. **证明自己对** — 复盘是为了学习，不是为了辩护
2. **流于形式** — 走完流程但没有真正的洞察
3. **归因错误** — 把成功归因于自己，把失败归因于外部
4. **快速下结论** — 没有深入分析就给出结论
5. **情绪化表达** — 借复盘发泄情绪，而不是理性分析
6. **泛泛而谈** — "还行""一般""不太好"，没有具体事实支撑

### 如何避免

- 每个结论都问一句："支撑这个结论的事实是什么？"
- 每个归因都问一句："有没有其他可能的解释？"
- 每个计划都问一句："具体做什么？什么时候做？怎么衡量做到了？"
