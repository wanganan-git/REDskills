# 康奈尔笔记法

**核心**：结构化笔记，深度加工。记录、简化、背诵、思考、复习五步。
**适用场景**：听课、读文献、需要深度记忆的内容。

## 引导步骤

### Step 1 - Record记录
- 说明：在右侧主栏记录学习内容的要点，用简洁的语言
- 指令：请在右侧主栏记录你要学习的内容要点（可以用自己的话改写，不要照抄）

### Step 2 - Simplify简化
- 说明：在左侧副栏提炼关键词和问题
- 指令：请在左侧副栏为每条要点提炼关键词，或者写成问题的形式

### Step 3 - Recite背诵
- 说明：遮住右侧主栏，只看左侧关键词复述内容
- 指令：请遮住右侧主栏，只看左侧关键词，尝试复述完整内容

### Step 4 - Reflect思考
- 说明：在底部总结栏写下自己的理解和联想
- 指令：请在底部写下你对这部分内容的理解、联想、或疑问

### Step 5 - Review复习
- 说明：定期用左侧副栏自测
- 指令：请用左侧关键词自测，看能否完整复述右侧内容

## 检验标准
只看左侧关键词就能完整复述右侧内容即为合格。

## 笔记结构示意
```
┌──────────────┬──────────────┐
│   左侧副栏    │   右侧主栏    │
│  关键词/问题   │   要点记录    │
│              │              │
│  关键词1      │  详细内容1    │
│  关键词2      │  详细内容2    │
│  问题1？      │  详细内容3    │
│              │              │
├──────────────┴──────────────┤
│        底部总结栏            │
│   自己的理解、联想、疑问      │
└─────────────────────────────┘
```
