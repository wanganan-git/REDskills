# 拆书稿写作Skill

> **什么是拆书稿？**
> 拆书稿是将一本完整的非虚构类书籍，提炼为一篇可以"听"的文章。目标读者是想快速了解一本书核心观点、但没时间读完全书的人。典型场景：得到、樊登读书等平台的听书内容。

## 核心原则

**拆书不是缩写，是翻译。**

把书中的核心思想从"作者的表达方式"翻译成"读者一听就懂的方式"。保留思想，更换表达。

## 第一步：读完全书，建立全局理解

**必须完整读完全书内容再动笔。** 不要读了几章就开始写。

读完后，回答以下问题（写在心里或草稿里，不输出给用户）：

1. **这本书在回答什么问题？**（通常是一句话）
2. **作者的核心论点是什么？**（通常可以用"不是A，而是B"的句式）
3. **作者用几条规则/原则/步骤来支撑这个论点？**
4. **书中最有说服力的案例是哪几个？**（通常3-5个）
5. **这本书的结论是什么？**

## 第二步：重组结构——从章节到原则

原书的章节结构是为了论证服务的，拆书稿的结构是为了"让读者记住"服务的。

### 重组规则：

1. **提炼5-8条原则**：将全书内容重新组织为5-8条清晰的原则/建议。每条原则对应原书的一个或多个章节。
2. **按逻辑顺序排列**：原则之间要有递进或并列关系，让读者能感受到"一条接一条地变厉害"。
3. **每条原则独立成章**：每条原则都可以独立理解，但放在一起又构成完整体系。

### 原则提炼技巧：

- 原则标题必须是**可执行的建议**，不是抽象概念
  - 好："不要追随你的激情"
  - 差："关于激情的反思"
- 每条原则用**一句话就能说清楚**
- 如果一条原则需要用两段话才能解释，说明它太大了，需要拆分

## 第三步：写作拆书稿

### 输出格式

```markdown
#关于作者
[1-2句话介绍作者背景]

#关于本书
[1-2句话说明这本书在讲什么、解决什么问题]

#核心内容
[用一句话概括每条原则，用分号分隔，形成一个完整的句子]
例：一、不要追随你的激情；二、好工作是用强力的职场资本换来的；三、别在错误的工作上浪费时间；四、掌握工作的主动性；五、用持续的练习提升自己的竞争力；六、找到工作的使命感；七、想要有真正创新的想法，先进入到最前沿的领域。

#拆解内容文稿
[完整的拆书稿正文]
```

### 拆书稿正文写作规范

#### 开头（约200-300字）

**开头策略：先说常见观念 → 挑战它 → 引出书的核心观点**

开头必须做到：
1. 用一句大家都听过的话/观念开场（"我们常说..."、"你一定听过..."）
2. 立刻指出这个观念的问题
3. 引出这本书要告诉你的真相
4. 告诉读者：接下来我会给你X条建议

**示例：**
> 我们在日常生活中经常会听到这样的说法，工作要追随自己的激情、要做自己热爱的事、要追随自己的内心等等，但是这本书的作者认为，这些口号都是说给那些职场老手听的，如果你是个职场新手，没有职场资本，没有技能的积累，又没有任何的人脉关系，贸然地跟着那些激动人心的口号做，可能会让自己陷入非常不利的境地。

#### 每条原则（约400-600字）

每条原则的结构：

1. **标题**：` 第X个原则：[原则名称]`（空两格开头，用中文数字）

2. **概念解释**（1-2段）：用口语化的方式解释这个原则是什么意思。要像跟朋友聊天一样。
   - 用"你"而不是"读者"
   - 用短句，一个句子只说一件事
   - 用"你想一想"、"咱们举个例子"、"换句话说"等口语过渡

3. **案例讲述**（1-2段）：用书中的案例来证明这个原则。
   - 案例要压缩，只保留最核心的情节
   - 删除学术引用、数据细节、次要人物
   - 保留故事的情感冲击力
   - 用"作者就拿...说明问题"、"比方说"等引入

4. **实用建议**（1段）：告诉读者怎么用这个原则。
   - 用"所以"、"也就是说"、"这里强调一点"等过渡
   - 给出可执行的行动建议

**语言风格要求：**

| 原书风格 | 拆书稿风格 |
|---------|----------|
| 激情假设认为，要获得职业幸福，关键是首先搞清楚自己的激情所在 | 追随你的激情去找工作，那就是在给你自己增加难度 |
| 根据自我决定理论，三种基本心理需求是... | 科学家发现，人要做好一件事，需要三个条件... |
| 这一结果是对激情假设的又一次冲击 | 这个发现直接打脸了"追随激情"的说法 |
| 被调查的学生当中，84%的人被确认为拥有激情 | 调查发现，84%的学生都说自己有激情 |

**口语化技巧清单：**
- "你想一想" → 引导读者思考
- "咱们举个例子" → 引入案例
- "说到这你可能也发现了" → 总结过渡
- "其实" → 揭示真相
- "换句话说" → 简化复杂概念
- "这里强调一点" → 突出重要信息
- "你可能会说了" → 预设读者疑问并回答

#### 结尾总结（约200-300字）

1. 用"总结"或"最后让我们来总结一下"开头
2. 把所有原则用**一句话**重新概括，用"第一条"、"第二条"等编号
3. 最后用一个**金句**收尾，可以是书中的原话，也可以是对全书的升华

**示例：**
> 说到这你可能也发现了，其实优秀的人总是会和自己玩一些思维的游戏，其实做的事还是原来的事，人也是原来的人，只不过普通人很快就没有动力、没有目标了，但是优秀的人总是能和自己玩游戏来获得源源不断的动力。

## 第四步：自检清单

写完后，逐条检查：

- [ ] 开头是否用常见观念引入，然后挑战它？
- [ ] 是否有5-8条清晰的原则？
- [ ] 每条原则是否都是可执行的建议？
- [ ] 每条原则是否都有案例支撑？
- [ ] 语言是否足够口语化，像在跟朋友聊天？
- [ ] 是否删除了学术引用和次要细节？
- [ ] 结尾是否有金句收尾？
- [ ] 全文是否流畅，像一篇完整的文章而不是碎片拼接？
- [ ] 读者听完是否能记住至少3条原则？

## 注意事项

1. **不要剧透太多**：拆书稿的目的是让读者想读原书，而不是替代原书。保留核心观点，但不要把所有案例都讲完。
2. **不要加自己的观点**：拆书稿是作者的观点，不是你的。不要说"我认为"、"我觉得"。
3. **保持作者的立场**：如果作者在书中挑战了某个常识，拆书稿也要保持这个挑战姿态。
4. **案例要真实**：所有案例必须来自原书，不要编造。
5. **字数控制**：拆书稿总字数一般在2000-4000字之间，取决于原书的厚度和复杂度。
